## Supplied rules

1. AI is allowed and encouraged in every assignment; only the final exam is written without it.
2. Declare AI use in `AI-LOG.md`, included with every project milestone PA#1–PA#5.
3. Students own their code; “AI wrote it” is not a defence.
4. Students may be asked to explain anything; what they cannot explain scores zero even if it runs.
5. No API keys, real user data or classmates' work in prompts.
6. For the product's LLM feature, explain what data leaves the system and why that is acceptable.

The pasted heading says “five rules” but enumerates six; preserve all six. Heavy disclosed use is not penalized by itself. A log is an account, not a transcript; concise honest entries are sufficient. Write as work happens. `Rejected` and `By hand` receive particular attention.

## Supplied entry format

```md
## YYYY-MM-DD — work or milestone
Tool: actual tool, or none.
Asked for: actual task in one sentence.
Kept: output retained.
Changed: edits and reasons; distinguish human edits from AI edits requested by a person.
Rejected: discarded suggestions and actual reasons, or none.
By hand: actual human-authored work or decisions; say when there is no manual code.
```

The date is when the log entry/work happened, using the student's timezone. A recovered entry must disclose that it was reconstructed from available evidence. Never manufacture a human review to make a log sound better.
